# Владимир — сайт фотографа

Одностраничный сайт-портфолио: обложка, галерея работ с просмотром, блок «обо мне»,
услуги с ценами и контакты со ссылками на соцсети.
Светлый минимализм: тёплая бумага, тонкие линии, крупная антиква, много воздуха.

Всё статичное — HTML + CSS, плюс небольшой `script.js` без зависимостей
(меню на телефоне, появление блоков, лайтбокс). Шрифты подключаются с Google Fonts.
Готово к публикации на GitHub Pages: относительные пути, `.nojekyll`, `404.html`.

## Как открыть локально

Двойной клик по `index.html` — сайт откроется в браузере. Сборка не нужна.

## Структура

```
index.html                  разметка и весь текст
styles.css                  стили (цвета и шрифты — в :root сверху)
script.js                   меню, анимации, просмотр фото
404.html                    страница «не найдено» для GitHub Pages
.nojekyll                   отключает Jekyll — файлы публикуются как есть
.gitignore                  служебный мусор вроде .DS_Store
images/                     фотографии (сейчас — заглушки)
  photo-01.jpg … photo-06.jpg   шесть работ в галерее
  about-portrait.jpg            портрет для блока «обо мне»
  og-image.jpg                  картинка для превью ссылки (1200×630)
preview/                    скриншоты сайта (для сайта не нужны)
tools/                      служебные скрипты (для сайта не нужны)
README.md                   этот файл
```

## Публикация на GitHub Pages

### Вариант 1 — без git, через сайт GitHub (проще всего)

1. Создайте репозиторий: **New repository** → любое имя, например `photo` →
   **Public** → **Create repository**.
2. Нажмите **uploading an existing file**.
3. Перетащите в окно **содержимое** папки: `index.html`, `404.html`, `styles.css`,
   `script.js`, папку `images`, файлы `.nojekyll` и `.gitignore`.
   Важно: именно файлы, а не саму папку — `index.html` должен оказаться
   в корне репозитория, иначе будет 404.
   Точки в начале имён (`.nojekyll`) не прячьте — эти файлы тоже нужны.
4. **Commit changes**.
5. **Settings → Pages** → *Build and deployment*:
   **Source: Deploy from a branch**, **Branch: `main`**, папка **`/ (root)`** → **Save**.
6. Подождите 1–2 минуты и обновите страницу Pages: там появится адрес
   `https://USERNAME.github.io/REPO/`.

### Вариант 2 — через git в терминале

```bash
git init
git add .
git commit -m "Сайт фотографа"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

Дальше — тот же пункт 5 (Settings → Pages → ветка `main`, папка `/ (root)`).

### Чек-лист: что должно лежать в корне репозитория

```
index.html                    главная
styles.css                    ← без него сайт выглядит как голый текст
script.js                     ← без него нет меню и просмотра фото
404.html                      страница «не найдено»
.nojekyll                     отключает Jekyll
images/                       папка целиком
  photo-01.jpg … photo-06.jpg
  about-portrait.jpg
  og-image.jpg
```

Необязательно, но полезно: `README.md`, `preview/`, `tools/`, `.gitignore`.

Быстрая самопроверка после деплоя — откройте в браузере
`https://USERNAME.github.io/REPO/styles.css`. Если отдаётся CSS-текст —
всё на месте; если страница GitHub «Site not found» или 404 — файл не загрузился.

### Проверка после публикации

- Откройте адрес сайта: обложка, галерея с просмотром фото и мобильное меню
  (сузьте окно) должны работать.
- Если картинки не появились — скорее всего папка `images` не загрузилась или
  легла во вложенную папку.
- **Превью ссылки.** Telegram и WhatsApp кешируют карточку ссылки надолго.
  Проверить свежую картинку можно через бота `@WebpageBot` (отправьте ему URL).
- Обновления появляются не мгновенно: GitHub Pages кеширует страницы примерно
  на 10 минут, браузер — тоже (жёсткое обновление: Ctrl+F5).

### Свой домен (по желанию)

1. Создайте в корне файл `CNAME` с одной строкой — доменом: `vladimir.ru`.
2. В настройках DNS у регистратора: `A`-записи на IP GitHub Pages
   (`185.199.108.153`, `.109.153`, `.110.153`, `.111.153`) и `CNAME` для `www`.
3. Settings → Pages → **Custom domain** → введите домен → **Enforce HTTPS**.
4. После этого поменяйте адрес в `canonical` и `og:url` на свой домен.

## Как заменить фотографии

1. Положите свои файлы в `images/`. Проще всего — под теми же именами
   (`photo-01.jpg` … `photo-06.jpg`), тогда разметку менять не нужно.
2. Если пропорции отличаются, поправьте `width`/`height` у `<img>` — они нужны,
   чтобы страница не «прыгала» при загрузке.
3. Для просмотра в полном размере можно указать отдельный файл:
   `data-full="images/photo-01-large.jpg"` у кнопки `.work-btn`.
4. Подписи к работам — `data-caption` (просмотр) и `work-title` / `work-meta` (в сетке).

Рекомендации: длинная сторона 1600–2000 px, JPEG качеством 80–85, вес до 400 КБ;
для обложки и «обо мне» — вертикальные кадры 3:4 и 4:5.

Добавить ещё работу: скопируйте любой `<figure class="work">…</figure>` целиком.
Удалить — удалите его же. Сетка сама перестроится (колонки 3 → 2 → 1).

Колонки — обычный CSS-masonry (`columns`), поэтому низ сетки выглядит ровно,
пока в каждой колонке идёт пара «высокий кадр + невысокий». Сейчас это
3:4 / 4:5 / 5:7 (вертикальные) в паре с 3:2 / 8:5 (горизонтальные).
Если добавите кадры с другими пропорциями, следите за итоговой высотой колонок.

Текущие файлы — сгенерированные заглушки: в левом нижнем углу у каждой стоит
светлая подпись (`01 / портрет`), чтобы было понятно, какой слот чем заменить.

## Цвета, шрифты, отступы

Всё в `:root` в начале `styles.css`:

```css
--paper: #faf8f4;      /* фон */
--paper-soft: #f3efe8; /* блок контактов */
--ink: #17130f;        /* текст */
--ink-soft: #6e665c;   /* вторичный текст */
--line: #e3dcd1;       /* линии */
--accent: #8a6a4c;     /* курсивные акценты и ховеры */
```

Шрифты — `Cormorant Garamond` (заголовки) и `Inter` (текст), подключены в `<head>`
через Google Fonts. Без интернета браузер возьмёт запасные Georgia / system-ui.
Чтобы работало офлайн, скачайте `.woff2` в папку `fonts/` и подключите через `@font-face`.

## Другие хостинги

- **Netlify / Vercel**: перетащите папку в окно деплоя — сайт готов.
- **Обычный хостинг**: залейте файлы по FTP в корень домена.

## Если захочется доработать

- **Форма заявки.** Сейчас связь идёт через почту и мессенджеры — самое надёжное для
  статического сайта. Если нужна форма, проще всего Formspree или аналогичный сервис:
  форма уходит на их адрес, ответы приходят на почту, бэкенд не нужен.
- **Отдельные страницы под каждую серию.** Галерею можно разложить на `work-01.html` и т. д.
- **Свои шрифты.** Если нужен характерный шрифт, замените пару `--serif` / `--sans`.
