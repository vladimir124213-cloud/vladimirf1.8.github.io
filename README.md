# Владимир — сайт фотографа

Одностраничный сайт-портфолио: обложка, галерея работ с просмотром, блок «обо мне»,
услуги с ценами и контакты со ссылками на соцсети.
Светлый минимализм: тёплая бумага, тонкие линии, крупная антиква, много воздуха.

Всё статичное — HTML + CSS, плюс небольшой `script.js` без зависимостей
(меню на телефоне, появление блоков, лайтбокс). Шрифты подключаются с Google Fonts.
Готово к публикации на GitHub Pages: относительные пути, `.nojekyll`, `404.html`.

## Как открыть локально

Двойной клик по `index.html` — сайт откроется в браузере. Сборка не нужна.

## Структура

```
index.html                  разметка и весь текст
styles.css                  стили (цвета и шрифты — в :root сверху)
script.js                   меню, анимации, просмотр фото
404.html                    страница «не найдено» для GitHub Pages
.nojekyll                   отключает Jekyll — файлы публикуются как есть
.gitignore                  служебный мусор вроде .DS_Store
images/                     фотографии
  photo-01.jpg … photo-06.jpg   шесть работ в галерее (все 2:3, вертикальные)
  about-portrait.jpg            кадр для блока «обо мне» (4:5)
  og-image.jpg                  превью ссылки для мессенджеров (1200×630)
preview/                    скриншоты сайта (для сайта не нужны)
tools/prepare_photos.py     готовит кадры из оригиналов: ресайз, кроп, вес
tools/shoot.mjs             скриншоты страницы через CDP (для проверки вёрстки)
README.md                   этот файл
```

## Как заменить фотографии

1. Положите файлы в `images/` под теми же именами
   (`photo-01.jpg` … `photo-06.jpg`, `about-portrait.jpg`, `og-image.jpg`) —
   тогда разметку трогать не нужно.
2. Обязательно поправьте `width`/`height` у `<img>`, если пропорции новые:
   они нужны, чтобы страница не «прыгала» при загрузке.
3. Для просмотра в полном размере можно указать отдельный файл:
   `data-full="images/photo-01-large.jpg"` у кнопки `.work-btn`.

Сейчас все кадры вертикальные 2:3 и лежат тремя колонками по два — низ сетки ровный.
Если добавите горизонтальный кадр, колонки разъедутся по высоте: либо подберите пары
(высокий + невысокий), либо сделайте под него отдельный блок.

Чтобы быстро привести новые оригиналы к нужным размерам, поправьте список
`FIELD_MAP` в `tools/prepare_photos.py` и запустите:

```powershell
python tools/prepare_photos.py
```

Скрипт делает ресайз до 1100–1200 px по ширине, JPEG качества 82, прогрессивный,
и отдельно собирает `about-portrait.jpg` (кроп 4:5) и `og-image.jpg` (1200×630).

## Публикация на GitHub Pages

Репозиторий: `vladimir124213-cloud/vladimirf1.8.github.io`, сайт:
`https://vladimir124213-cloud.github.io/vladimirf1.8.github.io/`

### Обновить уже опубликованный сайт

1. Откройте репозиторий → **Add file → Upload files**.
2. Перетащите изменённые файлы: `index.html` и **папку `images`** целиком
   (при замене фото — все файлы папки).
3. **Commit changes** → подождите минуту, обновите сайт через Ctrl+F5.

### С нуля (если репозиторий пустой)

1. **New repository** → **Public** → **Create repository**.
2. **uploading an existing file** → перетащите содержимое архива: `index.html`,
   `404.html`, `styles.css`, `script.js`, папку `images`, файлы `.nojekyll` и `.gitignore`.
3. **Commit changes**.
4. **Settings → Pages** → *Source: Deploy from a branch* → ветка `main`,
   папка `/ (root)` → **Save**. Через 1–2 минуты появится адрес.

### Чек-лист: что должно лежать в корне репозитория

```
index.html
styles.css        ← без него сайт выглядит как голый текст
script.js         ← без него нет меню и просмотра фото
404.html
.nojekyll
images/           папка целиком, не отдельные файлы в корне
```

Быстрая самопроверка: откройте `…/styles.css` в браузере — должен отдаться CSS-текст.
Если 404 или «Site not found» — файл не загрузился.

### Проверка после публикации

- Обложка, галерея с просмотром и мобильное меню (сузьте окно) должны работать.
- **Превью ссылки.** Telegram и WhatsApp кешируют карточку надолго; свежую
  можно проверить через бота `@WebpageBot`.
- GitHub Pages кеширует страницы ~10 минут, браузер тоже (Ctrl+F5).

### Свой домен (по желанию)

1. Файл `CNAME` в корне с одной строкой — доменом: `vladimir.ru`.
2. DNS у регистратора: `A`-записи на `185.199.108.153`, `.109.153`, `.110.153`,
   `.111.153` и `CNAME` для `www`.
3. Settings → Pages → **Custom domain** → **Enforce HTTPS**.
4. Адрес в `canonical` и `og:url` поменять на свой домен.

## Другие хостинги

- **Netlify / Vercel**: перетащите папку в окно деплоя.
- **Обычный хостинг**: залейте файлы по FTP в корень домена.

## Если захочется доработать

- **Форма заявки.** Сейчас связь идёт через почту и мессенджеры — самое надёжное для
  статического сайта. Если нужна форма, проще всего Formspree: форма уходит на их адрес,
  ответы приходят на почту, бэкенд не нужен.
- **Отдельные страницы под серии.** Галерею можно разложить на `work-01.html` и т. д.
- **Свои шрифты.** Замените пару `--serif` / `--sans` и подключите `.woff2` локально.
